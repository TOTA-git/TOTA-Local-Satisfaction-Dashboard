# TOTA-Local-Satisfaction

An interactive **R Shiny dashboard hosted by Posit Connect Cloud** that brings together publicly available local satisfaction data for the Thompson Okanagan region.

The dashboard was developed by the **Thompson Okanagan Tourism Association (TOTA)** to support local satisfaction reporting for the **UN Tourism International Network of Sustainable Tourism Observatories (INSTO)**. This dashboard contributes to ongoing efforts to better understand the relationship between local residents and tourism in the Thompson Okanagan Region.

## Dashboard

**Live App:** https://tota2-local-satisfaction-dashboard.share.connect.posit.cloud/

## Features

* Tourism Industry - residents agreement on tourism
* Tourism & Community - seasonal perceptions
